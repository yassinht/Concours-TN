# D. Complete Curriculum Structure

> القاعدة: لا نعلن أن موضوعًا "ضمن البرنامج" إلا إذا كان في نص رسمي. لذلك لكل عقدة في المنهج `scope`:
> `OFFICIAL_PROGRAM` (نص رسمي + صفحة) · `INFERRED_FROM_PAST_EXAMS` (مستنتج من امتحانات سابقة موثقة) · `GENERAL_SKILL` (مهارة عامة مشتركة بين كل المناظرات) · `SUGGESTED` (اقتراح تحريري — للتحقق).
> البيانات الفعلية: `content/syllabus/common.json` (المهارات العامة) + `specialty_syllabus` داخل ملفات `content/competitions/*.json` و`content/questions/spec-*.json`.

## D.1 البنية

```
Family (مناظرة)           مثال: حافظ أمن
└── Position (رتبة)        مثال: حافظ أمن متربص
    ├── Eligibility        شروط (سن، شهادة، جنس، طول، حالة مدنية) + مصدر
    ├── Phases             كتابي → رياضي → طبي → نفسي-تقني → شفاهي (+ إقصائي؟)
    ├── Subjects           مواد الكتابي (ضارب، مدة، عدد أسئلة إن عُرف)
    ├── Blueprint          وصفة الامتحان التجريبي (أقسام، عدد، وقت، fidelity)
    └── Syllabus links     ↓
Syllabus
├── SUBJECT  (مادة)        cg · ar · fr · en · lo · nu · ps · spec.*
│   └── TOPIC (محور)       cg.tunisie-institutions …
│       └── Objectives     cg.tunisie-institutions.o1 …
│           └── Questions  (كل سؤال مربوط بهدف واحد على الأقل)
│           └── Lessons    (درس 5–15 دقيقة لكل محور)
```

## D.4 مثال كامل: مسار "حافظ أمن" (MVP)

| المرحلة | ماذا نقدم | الحالة المعرفية |
|---|---|---|
| شروط الترشح | فاحص أهلية آلي + اقتباس البلاغ | OFFICIAL (بلاغ الدورة) |
| الكتابي | 1) موضوع ثقافة عامة (تحرير بالعربية) 2) QCM | بنية: SECONDARY/OFFICIAL حسب البلاغ؛ المحتوى: INFERRED/GENERAL |
| تحضير التحرير | قوالب موضوع (مقدمة/عرض/خاتمة)، 30 موضوعًا مقترحًا، تصحيح ذاتي بشبكة تقييم | SUGGESTED |
| QCM | cg + ar + lo + nu + spec.securite-droits | GENERAL_SKILL / SUGGESTED |
| نفسي-تقني | ps.* (مولدات خوارزمية + أسئلة) | GENERAL_SKILL |
| رياضي | متتبع أداء (100م، 1000م، عقلة…) + برنامج تدريب 8 أسابيع عام | البارام: **للتحقق** — لا نعرض أرقامًا غير موثقة كشروط |
| طبي | قائمة تحقق (النظر 15/20 حين يُذكر رسميًا) | حسب البلاغ |
| شفاهي | 40 سؤالًا شائعًا في المقابلة + نصائح سلوك | COMMUNITY/SUGGESTED |
| الوثائق | Checklist شخصي | OFFICIAL (البلاغ) |
| المحاكاة | Mock بنفس عدد الأسئلة/الوقت **إن نُشر رسميًا**، وإلا `APPROXIMATED` مع تنبيه | |

## D.5 الدروس

- درس قصير لكل محور (5–15 دقيقة): تعريف، 3–5 أفكار أساسية، مثال، أخطاء شائعة، 5 أسئلة تثبيت.
- تُولَّد بمساعدة AI **كمسودة**، تُراجع من مختص، تحمل المصدر إن كانت تخص معلومة تونسية (دستور، تنظيم إداري).
