## G. UX/UI (Mobile First, RTL first)

### G.1 مبادئ

1. **أول قيمة خلال 60 ثانية**: من رابط TikTok → سؤال حقيقي → نتيجة. التسجيل يأتي *بعد* أول تجربة وليس قبلها.
2. **عربي أولًا مع الفرنسية**: الواجهة بالعربية؛ أسئلة الفرنسية بالفرنسية (LTR داخل RTL بشكل صحيح). خيار تبديل اللغة.
3. **الثقة قبل الجمال**: شارة المصدر (🟢 رسمي / 🟡 ثانوي / ⚪ مجتمع) ظاهرة في كل صفحة معلومات.
4. **إبهام واحد**: أزرار الإجابة في النصف السفلي، حجم ≥ 48px.
5. **Gamification خفيفة**: streak و XP في الشريط العلوي فقط؛ الشاشة الرئيسية = "مهمة اليوم" وليست لوحة نقاط.

### G.2 الـ User Flow

```
Landing (/ أو /concours/douane-2026 من SEO أو إعلان)
  │  "استعد لمناظرتك خطوة بخطوة"  [ابدأ اختبار تشخيصي مجاني – 10 دقائق]
  ▼
Choose concours ──► Choose position (رتبة)
  ▼
Eligibility check (3–5 أسئلة: السن، الشهادة، الجنسية، الطول إن كان شرطًا رسميًا)
  │  النتيجة: "تستوفي الشروط المعلنة في بلاغ 2025" + رابط المصدر   أو  "شرط السن: الحد الأقصى X — راجع البلاغ"
  ▼
Diagnostic test (20–30 سؤالًا موزعة على مواد الامتحان، ~15 دقيقة)
  ▼
Results (بدون تسجيل: النتيجة الإجمالية فقط)
  │  [سجّل لترى التحليل الكامل وخطة دراستك]  ← magic link / Google
  ▼
Personal study plan (تاريخ الامتحان المتوقع، دقائق/يوم)
  ▼
Home = Daily mission ──► Lessons ──► Practice ──► Tutor
  ▼                                         
Mock exam (Premium، أو 1 مجاني) ──► Weakness analysis ──► Readiness
```

### G.4 Gamification (بحدود)

- **ضمن V1**: Daily streak، XP (1 لكل إجابة صحيحة، +bonus للمهمة اليومية)، شريط تقدم المنهج.
- **V2**: مستويات، شارات، ترتيب أسبوعي **حسب المناظرة** (لا ترتيب عام)، ترتيب Mock exam (percentile فقط: "أنت ضمن أفضل 20%").
- **ممنوع**: XP على السرعة بدل الدقة، مكافآت تشجع على النقر العشوائي. XP يُمنح للإجابة الصحيحة ولإكمال مراجعة الأخطاء.

## Content Moderation / Quality Control

### Workflow موحد لكل محتوى (fact, syllabus node, objective, lesson, question)

```
DRAFT ──(auto-validators)──► AI_REVIEWED ──(human)──► HUMAN_REVIEWED ──(publish)──► PUBLISHED ──► ARCHIVED
  ▲                               │                        │                            │
  └────────── rejected ◄──────────┴────────────────────────┘          user reports ≥ 3 ─┘ → يعود إلى المراجعة
```

- **AI لا ينشر أبدًا**: انتقال `→ PUBLISHED` يتطلب `reviewed_by` بشري (قيد في الـ backend، ليس فقط في الواجهة).
- **Facts رسمية** (شروط/مواعيد/مراحل): مراجعة بشرية مع اقتباس حرفي + رقم صفحة إلزاميان.
- **Re-verification**: كل fact لدورة مفتوحة يُعاد التحقق منه عند صدور أي بلاغ جديد؛ تنبيه في الـ dashboard إذا `last_verified_at` > 30 يومًا لمناظرة مفتوحة.
- **Kill switch**: تعطيل سؤال فورًا من الـ dashboard يزيله من كل الحزم والـ caches.
- **سجل كامل** (`content_review`, `audit_log`): من غيّر ماذا ومتى.
- **مراجع متخصص** لكل مادة تخصص (قانون إداري، ديوانة...) — عقد بالقطعة مع أستاذ/إطار متقاعد (انظر النموذج المالي).
